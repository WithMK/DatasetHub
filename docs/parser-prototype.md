# 표준 로그 기본 파서

수집된 원본 `.log`를 해시로 다시 확인한 후 UTF-8(BOM 허용)로 스트리밍합니다. 첫 줄의 `SEM_LOG_Version=2.0`과 정확한 11열 헤더는 건너뜁니다. 11필드 탭 구분, `yyyy-MM-dd HH:mm:ss.fff` 시각, `Start/End/Event`를 검증합니다. 500행마다 `LogRows`와 `ParseState`를 하나의 SQLite 트랜잭션으로 확정합니다.

유효 행은 필드와 물리적 줄 번호를 등록하고, 잘못된 행은 `ParseError`와 줄 번호를 기록합니다. 추가 탭은 추측해 결합하지 않습니다. 동일 파일을 다시 실행하면 완료된 해시를 건너뛰며, 중단 시 같은 행 키에 다시 기록하고 계속 진행합니다. 원본은 그대로 유지합니다. 콘솔의 `Parsed`는 해당 실행에서 새로 파싱한 유효 행 수, `InvalidRows`는 파일의 유효하지 않은 행 수입니다. 잘못된 행이 있으면 종료 코드 1입니다.

실제 인코딩·헤더·Data의 탭/이스케이프 규칙이 아직 미정이므로 이 파서는 합성 로그 기준입니다. UTF-8 이외의 파일은 오류로 남기고 수집된 원본을 보존합니다. 파일별 파싱 실패는 수집 상태와 별개로 `ParseState`에 기록합니다. 실제 로그 샘플을 받은 뒤 규칙을 확정해야 합니다.
