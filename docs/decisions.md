# 설계 결정과 미정 사항

## 확정

- 중앙 서버 1대에서 수집·파일 보관·SQLite 등록을 수행합니다.
- 설비 수는 가변이며 기본 설비 구성은 제어 PC 1대 + 검사 PC 2대입니다.
- 각 PC의 C와 D는 다른 물리 저장장치입니다. D의 SSD/HDD는 미정입니다.
- 서버가 사내망 SMB 공유폴더의 날짜·시간별 데이터를 PULL합니다.
- 실시간성보다 원본 정확성과 재수집·누락 점검을 우선합니다.
- 파일별 복사→검증→해석→DB 등록을 하나의 수집 작업 흐름으로 처리합니다.
- 표준 로그 기본 경로는 D:\Log\Standard\yyyyMMdd\<시간폴더>입니다. 루트·세부 이름은 설정으로 변경하며 일→시간 계층을 유지합니다. 이미지·JSON 경로는 별도입니다.
- 입력 텍스트는 SEM_LOG 2.0 표준 11필드 탭 구분 .log입니다.
- 1차 DB 등록은 파일 관리 정보와 표준 로그 기본 이벤트를 포함합니다. JSON·상세 Data 해석은 규약 확정 후 추가합니다.
- 초기 용량 계획은 통바당 200MB, 설비당 120초입니다.
- 9대 계산 예시는 1.296TB/일이며 설비 대수 제한이 아닙니다.
- 일반 이미지는 30일, NG·특이·대표 OK·Dataset 사용 원본은 보호 규칙을 적용합니다.
- 자동 삭제는 초기 구현에서 비활성화합니다.

## 미정

- 표준 로그의 실제 인코딩·헤더/버전행·닫힘·Data 상세 표현과 업체 JSON 스키마
- 완료 마커·Manifest·임시명 계약, Source Revision
- 검사 PC별 기능 분담과 카메라·NIC 구성
- OS/개발 SDK 세부 버전, 패키지 반입·설치 권한
- 실제 공유 경로·서비스 계정·서버 볼륨과 자격증명 보관
- 실측 전송 속도·동시성·재시도·수집 시각
- 장기 보존기간·용량 예산·로컬 삭제 ACK
- 모델 목적·라벨 규약·상용 학습 도구 Export

## 원칙

미정 형식은 모의 계약으로 분리하고 실제 장비 호환 완료로 표시하지 않습니다.
등록 대수와 동시 수집 수는 별도 설정입니다.
